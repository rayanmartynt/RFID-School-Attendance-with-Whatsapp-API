RFID Attendance System - Wiring Diagram
========================================

Arduino UNO R4 WiFi Pinout
--------------------------

RC522 RFID Reader Module:
  SDA (SS)  → Arduino Pin 10
  SCK       → Arduino Pin 13
  MOSI      → Arduino Pin 11
  MISO      → Arduino Pin 12
  RST       → Arduino Pin 9
  3.3V      → Arduino 3.3V
  GND       → Arduino GND

LCD 16x2 1602 (Parallel Connection):
  RS        → Arduino Pin 2
  EN        → Arduino Pin 3
  D4        → Arduino Pin 4
  D5        → Arduino Pin A0
  D6        → Arduino Pin A1
  D7        → Arduino Pin A2
  VSS       → Arduino GND
  VDD       → Arduino 5V
  V0        → Arduino GND (for maximum contrast)
  RW        → Arduino GND
  A         → Arduino 5V (through 220Ω resistor)
  K         → Arduino GND

Green LED:
  Anode (+) → Arduino Pin 5 (with 220Ω resistor)
  Cathode (-) → Arduino GND

Red LED:
  Anode (+) → Arduino Pin 6 (with 220Ω resistor)
  Cathode (-) → Arduino GND

Buzzer:
  Positive  → Arduino Pin 7 (with 220Ω resistor)
  Negative  → Arduino GND

Power Supply:
  Arduino USB → Computer USB port (5V)
  External power → Arduino DC jack (7-12V) if needed

Notes:
------
- Use 220Ω resistors for LEDs to limit current
- Ensure proper grounding of all components
- Use stable power supply for reliable operation
- Keep wires short to reduce interference
- Test each component individually before full assembly
